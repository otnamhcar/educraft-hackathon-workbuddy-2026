# ADDENDUM — Penilaian R012 (klaim komersial/halal) di bawah Rulebook v2.0

**Reviewer:** edu-reviewer · **Tanggal:** 31 Oktober 2026
**Alasan:** Rulebook naik ke v2.0 dan menambahkan **R012** (klaim komersial, advertising, halal).
R012 belum pernah dinilai pada run `-001` maupun `-002`. Addendum ini menutup celah tersebut.
**Sifat:** aditif. Tidak ada putusan lama yang diubah, tidak ada laporan lama yang diedit.

---

## 1. Apa yang diuji

R012 menyatakan empat hal:

1. Klaim penyembuhan/efikasi produk = `REJECT`
2. Klaim halal tanpa nomor sertifikat + lembaga penerbit = `REJECT`
3. Superlatif komersial tanpa bukti ("terbaik", "nomor satu") = `REJECT`
4. Materi edukasi murni tanpa unsur komersial = `N/A` beralasan

## 2. Metode (dapat diulang)

```bash
grep -rniE "halal|sertifikat|bpom|testimoni|sembuh|menyembuhkan|terbaik|nomor satu|obat" \
  03_Hasil/materi_ajar 03_Hasil/edu_output_wujud_zat \
  --include=*.md --include=*.html \
  | grep -viE "width|height|font-size" \
  | grep -v "05_review\|audit_log\|grounding_report\|rulebook"
```

Pemeriksaan tambahan untuk klaim absolut:

```bash
grep -rn "100%" 03_Hasil/materi_ajar/*.md 03_Hasil/edu_output_wujud_zat/*.md | grep -v "width"
```

## 3. Hasil

| Pemeriksaan | Hasil mentah | Setelah deklarasi CSS dibuang | Kesimpulan |
|-------------|-------------:|------------------------------:|------------|
| Istilah klaim (halal, sertifikat, BPOM, testimoni, sembuh, terbaik, obat, …) | 9 baris | **0 baris** | Tidak ada klaim komersial/halal/efikasi |
| Klaim absolut "100%" pada teks Markdown | 0 baris | 0 baris | Tidak ada klaim absolut |

Kesembilan temuan mentah seluruhnya berupa deklarasi CSS (`width:100%`, `table{width:100%}`) di file
HTML, bukan teks yang dibaca murid atau guru. Contoh: `quiz_interaktif.html:58`,
`08_Paket_Siswa_Cetak.html:35`.

## 5. Batas pemeriksaan

- Pencarian berbasis istilah, bukan ekstraksi simpul teks HTML. Istilah di luar daftar (misalnya
  merek dagang yang tidak dikenal) tidak akan tertangkap.
- Belum ada pemeriksaan otomatis untuk R012 setara `tools/check_grounding.py` untuk R001.
  **Rekomendasi:** tambahkan `tools/check_claims.py` dengan daftar istilah + pola superlatif sebelum
  Demo Day, agar R012 juga dapat didemokan, bukan hanya dideklarasikan.

## 6. Dampak pada submission

Tidak ada perubahan pada verdict R001–R011. Yang berubah: rulebook kini punya dasar untuk menolak
klaim komersial/halal, yaitu kriteria yang disebut eksplisit oleh handbook Challenge C. Pada
submission, R012 dapat disebut sebagai **"N/A with justification"**, bukan sebagai aturan yang
belum ada.
